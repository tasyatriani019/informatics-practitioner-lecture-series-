# 📊 Make Sense of Data with Analytics and AI

### Prediksi Keterlambatan Pembayaran Tagihan Mahasiswa

## Deskripsi
Implementasi kasus berdasarkan materi webinar *Make Sense of Data with Analytics and AI*, yang membahas pemanfaatan data analytics dan Artificial Intelligence untuk membantu pengambilan keputusan.

## Implementasi Kasus
Membangun model Machine Learning untuk memprediksi potensi keterlambatan pembayaran tagihan mahasiswa menggunakan algoritma **Decision Tree**.

## Tahapan
1. Menyiapkan dan melakukan preprocessing data.
2. Melatih model menggunakan data simulasi.
3. Mengevaluasi model dengan accuracy, precision, recall, dan F1-score.
4. Melakukan prediksi terhadap data tagihan baru.

## Tools
Python, Google Colab, Pandas, NumPy, dan Scikit-learn.
