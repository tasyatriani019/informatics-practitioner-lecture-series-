## 📌 Overview

This repository presents a practical case study inspired by the *Human-Computer Interaction & Data Visualization* practitioner lecture.

The project demonstrates how user interaction data can be analyzed and presented through charts and an interactive dashboard to help evaluate application usability.

## 🎯 Objectives

- Understand the relationship between Human-Computer Interaction (HCI) and Data Visualization.
- Analyze indicators of user experience and usability.
- Present data through clear and informative visualizations.
- Build an interactive dashboard for exploring usability results.
- Identify potential interface improvements based on the analysis.

## 💡 Case Study: Application Usability Evaluation Dashboard

**Problem:** How can user data help identify aspects of an application interface that may need improvement?

The implementation simulates user testing for an academic application. Each record represents a testing session and includes:

| Variable | Description |
|---|---|
| Device | Desktop, Mobile, or Tablet |
| Task | Activity performed by the user |
| Completion Time | Time required to complete a task |
| Task Success | Whether the task was completed successfully |
| Satisfaction Score | Simulated rating from 1 to 5 |

## ⚙️ Implementation Workflow

1. Generate a simulated usability dataset.
2. Calculate usability indicators.
3. Analyze task completion and satisfaction.
4. Visualize results using charts.
5. Build an interactive dashboard with a device filter.
6. Compare results across devices.
7. Generate simple recommendations for further interface evaluation.

## 📊 Dashboard Features

The notebook includes:

- **Usability Summary** — displays task success, average completion time, and satisfaction.
- **Task Success Chart** — compares task completion rates.
- **Completion Time Box Plot** — shows the distribution of task completion times.
- **Satisfaction Distribution** — summarizes user satisfaction scores.
- **Time vs. Satisfaction Scatter Plot** — explores the relationship between completion time and satisfaction.
- **Device Comparison** — compares usability indicators across Desktop, Mobile, and Tablet.
- **Interface Evaluation Recommendations** — identifies tasks that may require further review.

## ⚠️ Limitations

The dataset is simulated and does not represent real user testing. The analysis demonstrates a basic usability evaluation workflow rather than proving the usability of an actual application.

For further development, the project could incorporate real usability testing, user feedback questionnaires, accessibility evaluation, and more detailed interaction data.
