## 📌 Tentang Repository

Repository ini berisi dokumentasi pembelajaran dari kegiatan **Informatics Practitioner Lecture Series** yang bertujuan menghubungkan pengetahuan akademik dengan pengalaman industri, penelitian, dan perkembangan teknologi global.

Repository ini mencakup rangkuman materi, pemahaman konsep, implementasi kasus, visualisasi data, serta dokumentasi proyek yang dikembangkan berdasarkan topik setiap pertemuan.

Melalui kegiatan ini, saya mempelajari berbagai bidang dalam Informatika, mulai dari Data Analytics, Artificial Intelligence, Machine Learning, Human-Computer Interaction, hingga Geographic Information Systems dan High Performance Computing.

### 04. 🤖 Introduction to Machine Learning

**Folder:** [`introduction-to-machine-learning/`](./introduction-to-machine-learning/)

**Narasumber:** Taniza Tajuddin — Senior Lecturer, Universiti Teknologi MARA (UiTM), Cawangan Kedah

**Tanggal:** 15 Oktober 2026

**Implementasi Kasus:** Prediksi Kelulusan Mahasiswa Menggunakan Machine Learning

**Deskripsi**

Implementasi Machine Learning untuk memprediksi status kelulusan mahasiswa menggunakan algoritme Decision Tree dengan pendekatan Supervised Learning.

Data yang digunakan merupakan data simulasi dengan fitur IPK, persentase kehadiran, dan jumlah mata kuliah yang lulus.

**Komponen Implementasi**
- Pembuatan dan eksplorasi dataset.
- Preprocessing data.
- Pembagian data training dan testing.
- Pelatihan model Decision Tree.
- Evaluasi menggunakan Accuracy, Precision, Recall, dan F1-score.
- Visualisasi Confusion Matrix dan pohon keputusan.
- Pengujian prediksi pada data mahasiswa baru.
- Pembahasan keterbatasan model dan potensi bias.

**Teknologi:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, dan Google Colab.

**Tanggal:** 19 Oktober 2026

**Implementasi Kasus:** Dashboard Evaluasi Usability Aplikasi

**Deskripsi**

Implementasi evaluasi usability menggunakan data interaksi pengguna yang disimulasikan. Data divisualisasikan melalui grafik dan dashboard untuk membantu memahami keberhasilan pengguna menyelesaikan tugas, waktu pengerjaan, dan tingkat kepuasan.

### 06. 🌳 Attributing Direct Drivers to Deforestation Alerts with Satellite Imagery and AI

**Folder:** [`deforestation-alerts-satellite-ai/`](./deforestation-alerts-satellite-ai/)

**Narasumber:** Bart Slagter — Peneliti, Wageningen University & Research

**Tanggal:** 19 Oktober 2026

**Deskripsi**

Membahas pemanfaatan citra satelit dan Artificial Intelligence untuk mengidentifikasi faktor penyebab langsung deforestasi. Pendekatan ini dapat mendukung pemantauan hutan, analisis perubahan tutupan lahan, dan pemahaman terhadap penyebab deforestasi.

**Fokus Pembelajaran**
- Memahami pemantauan hutan menggunakan citra satelit.
- Mengenal peran citra Sentinel-1 dan Sentinel-2.
- Memahami penggunaan AI dan Deep Learning untuk klasifikasi penyebab deforestasi.
- Mengetahui pentingnya data pelatihan dan evaluasi model.
- Memahami keterbatasan klasifikasi serta perlunya validasi lapangan.

**Arah Implementasi:** Klasifikasi penyebab deforestasi menggunakan konsep Machine Learning dan visualisasi data.
