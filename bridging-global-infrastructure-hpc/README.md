# 🌏 Bridging Global Infrastructure to Address Local Challenges in HPC

### Simulasi Risiko Banjir Menggunakan Python

## Deskripsi
Implementasi kasus berdasarkan materi webinar tentang pemanfaatan *High Performance Computing* (HPC) untuk menyelesaikan permasalahan lokal melalui komputasi dan analisis data.

## Implementasi Kasus
Membuat simulasi risiko banjir berdasarkan data simulasi curah hujan dan elevasi wilayah. Hasil pengolahan ditampilkan dalam bentuk peta visualisasi untuk mengidentifikasi area dengan tingkat risiko berbeda.

## Tahapan
1. Membuat data simulasi curah hujan dan elevasi.
2. Menghitung skor risiko banjir.
3. Mengelompokkan tingkat risiko.
4. Memvisualisasikan hasil menggunakan Python.

## Tools
Python, Google Colab, NumPy, dan Matplotlib.
